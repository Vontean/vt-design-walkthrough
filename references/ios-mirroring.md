# iOS：iPhone Mirroring

此路径来自真实镜像验收。应用、设备和截图尺寸每轮重新识别。

1. 按 Computer 工具的初始化要求选择 iPhone Mirroring 窗口，读取工具文档和初始 UI。保存当前设备、系统及开发版包/版本；无法查看版本时说明信息缺失。
2. 用当前截图确认解锁、连接及目标应用状态。正常进入用户授权的测试版本，从已知入口开始首个用例。
3. 操作采用观察 → 定位 → 点击/滚动 → 再观察。滚动发生在镜像内容区域；先做一次适量滚动并检查内容确实移动，再批量推进。输入竞态时告知用户暂时让出镜像操作，不把工具无响应直接归为 app BUG。
4. 截图保存实际窗口原图，记录手机内容边界；若需提取完整手机区域，保留窗口原图并另存，记录两者关系。标注主图保留完整 source，局部裁剪仅作补充细节图。调用截图工具返回的原生文件，避免重复截图时丢失触发状态。
5. 系统权限沿用已有授权；新增不可推断的授权及时询问。无法继续的设备锁定请用户自行解锁，等待后重新观察；凭据由用户输入。
6. 工具超时先检查当前窗口状态；操作可能已生效。连续无法控制时保存本批、失败点及 next_action，再请求解除具体阻塞。

完成：当前用例在真实版本上取得可验证结果；工具/连接问题与产品问题有明确区分。
