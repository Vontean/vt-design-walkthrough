# Android：实机镜像（待实机验证）

共享用例、证据和交付流程已定义。本分支的具体连接、控制和截图路径尚未实机验证，运行时按下面的检查步骤建立已验证配置。

1. 识别真实测试设备、系统、开发包和现有镜像窗口；优先用户已连接且当前 Computer 工具可操作的镜像。scrcpy 等仅是可能的镜像载体，不假定已安装或可用。
2. 对首次设备接入，读取当前工具支持能力和设备提示。启用开发选项、调试或安装镜像工具如需改变用户环境，先说明必要性并取得授权；已有可用入口直接继续。
3. 执行短校准：点击、纵向滚动、文本输入、系统返回、应用返回、截图保存。核验每项在真实手机生效，记录工具入口及截图手机内容边界。
4. 从应用入口执行用例。区分 Android 系统组件与设计定义的自定义组件；系统权限、键盘和返回键按平台行为检查，不能用 iOS 外观作为 Android 正确依据。
5. 断开后保存当前用例和状态，连接恢复先读取真实画面再接续。Computer 控制不可用时切换到明确支持且授权的方式；否则记录阻塞并请用户恢复连接。
6. 本次实测完成后，把已验证入口、控制能力和限制写入项目 LOG.md。经用户要求再更新此参考文件，避免把单台设备配置固化成所有 Android 环境要求。
